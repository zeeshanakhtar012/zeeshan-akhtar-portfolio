# Zeeshan Akhtar — Mobile Product Engineer

Portfolio site for Zeeshan Akhtar, a mobile product engineer and startup technical partner building cross-platform apps for international founders.

## Stack

- Plain HTML + CSS + JS (single-file, no framework)
- Fonts: Instrument Serif, DM Sans, Geist Mono (Google Fonts)
- Icons: Inline SVG

## Sections

- **Hero** — Value thesis, metrics, profile
- **Work** — Case study (Baloch Transport) + shipped products grid
- **Approach** — Design & engineering philosophy
- **Services** — Engagement models for founders
- **Experience** — Career timeline
- **Contact** — Qualified lead form with launch window & budget selectors

## Local

Open `index.html` in any browser. No build step required.
